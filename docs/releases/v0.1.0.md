# v0.1.0 — 首个公开版本

给 agent 用的意图档案格式与协议：把"人与 LLM 的对话"沉淀为一份**独立于会话、可移植、可复现、可审计**的意图档案。会话删除、人机失忆后，仅凭【规范 + 档案】即可让任意模型重建出意图一致的产物。

## 亮点

- **IL 规范 v2.0**：五条根本原则（原则 0 = 记录优先、不干扰生成）+ 头四段/七段结构 + 跨档案引用 `<ref>`。
- **双通道对话内核**：LLM 回答用户的同时更新档案；L1 确定性检查 + L2 记录员分层保证合法性，**只记录、不干扰**。
- **复现闭环**：`repro` / `accept` / `demo` —— ACCEPT 行为验收 + SNIPPET 点名形态检查。
- **三种接入面，全部默认 BYOM（模型由调用方自带）**：
  - CLI：`chat` / `verify` / `repro` / `accept` / `lint` / `fmt` / `demo` / `log` / `show` / `rollback`
  - MCP server：`il mcp`（纯工具 + prompts + resources；配 provider 时可选用编排工具）
  - Go 库：`github.com/lovepk/intent-lang/pkg/intentlang`
- **多 Provider**：`--provider <name>` 接入任意 OpenAI 兼容端点（OpenAI / Qwen / 本地 Ollama…），key 可空；`demo --provider-a/--provider-b` 跨模型验证可移植性。
- **工程**：Apache-2.0 许可、GitHub Actions CI、`CONTRIBUTING.md`、VS Code 语法高亮、示例档案入库。

## 安装

```sh
go install github.com/lovepk/intent-lang/cmd/il@v0.1.0
# 国内网络建议：GOPROXY=https://goproxy.cn,direct go install ...
```

或从源码构建：

```sh
git clone https://github.com/lovepk/intent-lang && cd intent-lang
go build -o il ./cmd/il
```

## 快速开始

```sh
# 配一把自己的 key（.env）
# DEEPSEEK_API_KEY_A=sk-...

./il chat  --repo .il
./il lint  --archive .il/archive.last.il --fail-on error
./il repro --key B --archive .il/archive.last.il --out artifact.py
./il accept --archive .il/archive.last.il --artifact artifact.py
```
